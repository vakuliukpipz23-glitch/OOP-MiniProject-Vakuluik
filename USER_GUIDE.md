# USER_GUIDE

## Огляд
Цей документ пояснює, як користуватися консольним додатком Library Management System.

## Вимоги
- .NET 10 SDK
- Windows або інша платформа, сумісна з .NET 10

## Запуск
1. Відкрити термінал у корені проекту.
2. Виконати `dotnet run --project src/LibraryManagementSystem.Console`.
3. Виконувати інструкції меню.

## Основні кроки
1. **Register New Patron** — Створити нового відвідувача.
2. **List All Patrons** — Переглянути зареєстрованих відвідувачів.
3. **Register New Book** — Додати книгу до каталогу.
4. **List Available Books** — Подивитися доступні для позичання книги.
5. **Borrow a Book** — Позичити книгу за ISBN.
6. **Return a Book** — Повернути книгу за Borrow ID.
7. **View Patron's Borrows** — Переглянути історію позичень відвідувача.
8. **Search Books** — Знайти книги за запитом.
9. **Analytics & Reports** — Переглянути стан бібліотеки та статистику.
10. **Update Patron Contact** — Оновити email і телефон відвідувача.
11. **Update Book Category** — Оновити категорію книги.
12. **Save Library State** — Зберегти весь стан у JSON файл.
13. **Exit** — Вийти та зберегти стан.

## Демонстраційний сценарій
1. Запустити додаток.
2. Зареєструвати нового користувача.
3. Додати книгу.
4. Позичити книгу.
5. Переглянути історію позичень користувача.
6. Повернути книгу.
7. Зберегти стан.

## Негативний сценарій
- Спроба позичити книгу, коли всі копії зайняті.
- Спроба повернути вже повернену книгу.
- Спроба зареєструвати книги з дубльованим ISBN.

## Збереження та відновлення
- Стан зберігається у `data/library.json`.
- Після старту програми вона автоматично намагається завантажити збережений стан.
- Якщо файл пошкоджено, програма починає з чистого стану.
