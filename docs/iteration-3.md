# Iteration 3 (Lab 36) - Якість Коду та Тестування

## Мета
Покращити якість проекту через чітке розділення відповідальностей, обробку помилок та розширене тестове покриття.

## Що реалізовано
- Впроваджено спеціалізовані доменні виключення (`EntityNotFoundException`, `BusinessRuleViolationException`, `DuplicateEntityException`)
- Додано обробку помилок з персистенцією даних (`DataLoadException`, `DataSaveException`, `DataCorruptionException`, `PersistenceRestoreException`)
- Додано повтори при збереженні/завантаженні JSON-файлів для зменшення впливу тимчасових помилок I/O
- Розширено тестову частину інтеграційними сценаріями для збереження/завантаження
- Оновлено GitHub Actions для запуску покриття коду під час CI

## Результати
- Розширено тестову документацію та стратегічну матрицю тестування
- Додано перевірки відновлення стану бібліотеки з пошкоджених даних
- Удосконалено можливість розширення та підтримки завдяки кращій обробці помилок

## Фокуси для майбутнього
- Зв'язати покриття тестів із реальним порогом якості в CI
- Додати статичний аналіз (наприклад, SonarQube або Roslyn Analyzers)
- Розширити модель збереження даних для підтримки SQL/NoSQL
